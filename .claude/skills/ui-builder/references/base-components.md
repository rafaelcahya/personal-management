# Base Components (`components/base/`)

Every folder has a `Guide.stories.jsx` — read it for props, variants, and do/don't examples before using a component.

| Component           | Use for                                                                         | Import                                                                                                                                                                                                |
| ------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accordion           | Collapsible sections, FAQ, expandable rows                                      | `@/components/base/Accordion/Accordion`                                                                                                                                                               |
| Attachment          | File upload display, attachment groups                                          | `@/components/base/Attachment/...`                                                                                                                                                                    |
| Avatar              | User avatars, group avatars, status                                             | `@/components/base/Avatar/...`                                                                                                                                                                        |
| Badge               | Status labels, tags, counts                                                     | `@/components/base/Badge/Badge`                                                                                                                                                                       |
| Banner              | Info/warning/error/success banners                                              | `@/components/base/Banner/...`                                                                                                                                                                        |
| Breadcrumb          | Page hierarchy                                                                  | `@/components/base/Breadcrumb/...`                                                                                                                                                                    |
| Button              | Every clickable action                                                          | `import Button from '@/components/base/Button/Button'`                                                                                                                                                |
| Card                | Section containers                                                              | `import Card, { CardHeader, CardIcon, CardHeaderContent, CardTitle, CardDescription, CardContent } from '@/components/base/Card/Card.jsx'`                                                            |
| Checkbox            | Boolean / multi-select                                                          | `@/components/base/Checkbox/...`                                                                                                                                                                      |
| Collapsible         | Toggle-able content                                                             | `@/components/base/Collapsible/...`                                                                                                                                                                   |
| Color / ColorPicker | Color selection                                                                 | `@/components/base/ColorPicker/...`                                                                                                                                                                   |
| Combobox            | Searchable select                                                               | `@/components/base/Combobox/...`                                                                                                                                                                      |
| Command             | Command palette, keyboard search                                                | `@/components/base/Command/...`                                                                                                                                                                       |
| DatePicker          | Date, month, year inputs                                                        | `@/components/base/DatePicker/...`                                                                                                                                                                    |
| DropdownMenu        | Action and context menus                                                        | `@/components/base/DropdownMenu/...`                                                                                                                                                                  |
| EmptyState          | Empty list/table/section                                                        | `import { EmptyState, EmptyStateTitle, EmptyStateDescription } from '@/components/base/EmptyState/EmptyState'`                                                                                        |
| Field               | Form field wrapper (label, control, error, description)                         | `import { FieldContainer, FieldContent, FieldLabel, FieldError } from '@/components/base/Field/Field'`                                                                                                |
| HoverCard           | Rich hover previews                                                             | `@/components/base/HoverCard/...`                                                                                                                                                                     |
| Input               | Text input                                                                      | `import Input from '@/components/base/Input/Input'`                                                                                                                                                   |
| MarkdownEditor      | Rich text / markdown                                                            | `@/components/base/MarkdownEditor/...`                                                                                                                                                                |
| Modal               | Dialogs, confirmations, short forms                                             | `import { Modal, ModalTrigger, ModalContent, ModalHeader, ModalHeaderContent, ModalIcon, ModalTitle, ModalDescription, ModalBody, ModalFooter, ModalClose } from '@/components/base/Modal/Modal.jsx'` |
| NavMenu             | Navigation menus                                                                | `@/components/base/NavMenu/...`                                                                                                                                                                       |
| Pagination          | List/table paging                                                               | `@/components/base/Pagination/...`                                                                                                                                                                    |
| PasswordInput       | Password with show/hide                                                         | `@/components/base/PasswordInput/...`                                                                                                                                                                 |
| PinInput            | OTP / PIN                                                                       | `@/components/base/PinInput/...`                                                                                                                                                                      |
| Popover             | Floating content on a trigger                                                   | `@/components/base/Popover/...`                                                                                                                                                                       |
| RadioGroup          | Single-select options                                                           | `@/components/base/RadioGroup/...`                                                                                                                                                                    |
| RatingInput         | Star/numeric rating                                                             | `@/components/base/RatingInput/...`                                                                                                                                                                   |
| ScrollArea          | Custom scroll containers                                                        | `@/components/base/ScrollArea/...`                                                                                                                                                                    |
| Select              | Dropdown select                                                                 | `@/components/base/Select/...`                                                                                                                                                                        |
| SelectCard          | Card-style options                                                              | `@/components/base/SelectCard/...`                                                                                                                                                                    |
| Separator           | Dividers                                                                        | `@/components/base/Separator/...`                                                                                                                                                                     |
| Sheet               | Side panels / drawers                                                           | `@/components/base/Sheet/...`                                                                                                                                                                         |
| Sidebar             | App sidebar                                                                     | `@/components/base/Sidebar/...`                                                                                                                                                                       |
| Skeleton            | Loading placeholders                                                            | `import { Skeleton } from '@/components/base/Skeleton/Skeleton'`                                                                                                                                      |
| Slider              | Range input                                                                     | `@/components/base/Slider/...`                                                                                                                                                                        |
| Spinner             | Inline loading                                                                  | `@/components/base/Spinner/...`                                                                                                                                                                       |
| State               | Generic loading/error/empty display                                             | `@/components/base/State/...`                                                                                                                                                                         |
| Switch              | Toggle                                                                          | `@/components/base/Switch/...`                                                                                                                                                                        |
| Table               | Data tables                                                                     | `@/components/base/Table/...`                                                                                                                                                                         |
| Tabs                | In-page tabs                                                                    | `@/components/base/Tabs/...`                                                                                                                                                                          |
| Textarea            | Multi-line input                                                                | `import Textarea from '@/components/base/Textarea/Textarea'`                                                                                                                                          |
| Theme               | Theme helpers                                                                   | `@/components/base/Theme/...`                                                                                                                                                                         |
| TimePicker          | Time input                                                                      | `@/components/base/TimePicker/...`                                                                                                                                                                    |
| Toast               | Toast styling — call `toast` from `sonner` (`<Toaster>` is in `app/layout.tsx`) | `import { toast } from 'sonner'`                                                                                                                                                                      |
| Tooltip             | Short hints on hover/focus                                                      | `@/components/base/Tooltip/...`                                                                                                                                                                       |

Where the import column says `...`, check the folder for the exact file and whether it's a default or named export (`ls components/base/{Name}`).
